## EXACT SCRIPT (with lanes)

### 🎥 ON CAMERA — [0:00-0:15] Hook
**Say exactly:**
> "Salesforce mein ek sawaal har beginner ko confuse karta hai — ye kaam Flow se karun ya Apex se? Aaj ke baad, ye confusion gone. Main hoon Wishvesh Ujawane, welcome to Trailhead Simplified."

### 🎥 ON CAMERA — [0:15-0:40] Promise
**Say exactly:**
> "Is video mein teen cheezein — pehla, Flow aur Apex hain kya; doosra, ek simple rule jisse 90% cases aap khud decide kar paoge; teesra, ek real example. Chalo screen pe chalte hain."

*→ Transition: switch to screen-share now.*

### 🎙️ OFF CAMERA + 🖥️ SCREEN — [0:40-2:00] What is Flow
**🖥️ SHOW:** Setup → Flows → New Flow → Record-Triggered Flow. Hover slowly over canvas elements.
**🎙️ SAY:**
> "Flow matlab clicks, code nahi. Ye dekho — main bina ek line likhe automation bana sakta hoon. Record update, simple logic, approvals, screen flows — sab Flow se. Rule simple hai: agar admin akela kar sakta hai bina developer ke, wo Flow ka kaam hai."

### 🎙️ OFF CAMERA + 🖥️ SCREEN — [2:00-3:30] What is Apex
**🖥️ SHOW:** Developer Console (or VS Code) with a tiny ~8-line trigger/class. Scroll slowly; highlight one line with the cursor.
**🎙️ SAY:**
> "Apex matlab code. Jab logic complex ho, bulk data ho, ya kisi external system se baat karni ho — tab Apex. Ye snippet dekho — yahan main control le raha hoon jo Flow nahi de sakta. Ek line yaad rakho: jahan Flow thak jaaye, wahan Apex aata hai."

### 🎙️ OFF CAMERA + 🖥️ SCREEN — [3:30-5:00] The decision rule (slow down here)
**🖥️ SHOW:** A simple slide/notepad with 3 questions typed out; reveal one line at a time.
**🎙️ SAY:**
> "Teen sawaal apne aap se poocho. Ek — kya admin clicks se ho sakta hai? Haan toh Flow. Do — kya logic complex hai ya external system se baat karni hai? Haan toh Apex. Teen — kya bulk ya performance matter karta hai? Haan toh Apex. Default soch: Flow first, Apex when needed. Salesforce bhi yahi recommend karta hai — low-code pehle, code tab jab zaroorat ho."

### 🎙️ OFF CAMERA + 🖥️ SCREEN — [5:00-6:30] Real example
**🖥️ SHOW:** Side-by-side — left: a Flow doing a single Opportunity field update; right: an Apex class doing a 5000-record + API update.
**🎙️ SAY:**
> "Example ek — Opportunity close hone pe ek field update. Sirf Flow, simple. Example do — 5000 records ko external API ke data se update karna. Yahan Apex. Same goal, alag tool — kyunki scale aur complexity alag hai."

### 🎥 ON CAMERA — [6:30-7:00] Recap + CTA
*→ Switch back to face-cam.*
**Say exactly:**
> "Toh yaad rakho — Flow first, Apex when needed. Helpful tha? Ek like aur subscribe — har [day] naya Salesforce video. Comment mein batao: aapne aakhri baar Flow use kiya ya Apex? Chalo, Salesforce ko simple banate hain. Milte hain agle video mein!"
