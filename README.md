## How we work together
1. Each week, you tell me the topic (or pick from the Idea Bank).
2. I draft the **video script** (in the 3-lane format from CONTENT-RULES.md), **titles**, **description**, **tags**, **thumbnail text**.
3. I slice it into **2-3 reel scripts** with hooks, on-screen text, captions, and hashtags.
4. You record + edit in DemoCreator, then schedule.
5. We update the calendar + streak tracker in [CONSISTENCY.md](content/CONSISTENCY.md).
